# TypeScript Assignment: Problem Solving with TypeScript & OOP

## Assignment Overview

This repository contains my solutions to the TypeScript assignment, focusing on basic TypeScript concepts and Object-Oriented Programming (OOP).

The assignment covers:

- Functions and optional parameters
- Union types and type narrowing
- Tuples and readonly properties
- Generics and array operations
- Interfaces and type constraints
- Classes, inheritance, and access modifiers
- Asynchronous programming with Promises and async/await

All eight programming problems are implemented in `solutions.ts`.
